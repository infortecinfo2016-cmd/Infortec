# Icon

Ícones de linha desenhados para o Infortec RH: grade de 24px, traço de 1.75px, pontas arredondadas, herdam a cor do texto (`currentColor`).

**Props:** `name` (veja `Icon.names`), `size` (padrão 20), `label` (quando o ícone sozinho carrega significado; sem `label` ele é decorativo e fica oculto para leitores de tela).

- 20px na interface; 16px em botões pequenos, badges e metadados; 18px na barra lateral e em campos.
- Mapeamento por módulo: Painel `home`, Colaboradores `users`, Admissão `user-plus`, Ponto `clock`, Férias `calendar`, Folha `wallet`, Benefícios `gift`, Avaliações `star`, Relatórios `chart`, Documentos `file`.
- Faltou um ícone? Use Lucide (mesma linguagem de traço) com `stroke-width` 1.75.
