# Tabs

Abas para dividir uma mesma entidade em seções, como o perfil do colaborador. Setas ← → movem entre as abas.

**Props:** `items` (`{ id, label, count? }`), `value` + `onChange(id)` (controlado) ou `defaultValue`, `label` (nome acessível do grupo).

- Até 7 abas; rótulos de 1 a 2 palavras.
- `count` mostra pendências ou quantidade (documentos, solicitações), não status.
