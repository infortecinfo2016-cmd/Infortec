# Switch

Interruptor para configurações que valem na hora, sem botão Salvar.

**Props:** `label`, `checked` + `onChange(next)` (controlado) ou `defaultChecked` (não controlado), `disabled`.

- O rótulo descreve o estado ligado: “Permitir registro de ponto pelo celular”.
- Dentro de formulários com botão Salvar, use `Checkbox`.
