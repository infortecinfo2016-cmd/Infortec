# EmployeeCard

Resumo de uma pessoa colaboradora para grades de “Colaboradores”, organograma e resultados de busca.

**Props:** `name`, `role` (cargo), `status` (um status de `StatusBadge`), `department`, `registration` (matrícula), `admission` (dd/mm/aaaa), `manager`, `photo`, `onClick` (torna o cartão clicável e focável).

- Mostre só dados de identificação. Salário, CPF e endereço ficam no perfil, com permissão.
- Em listas longas (mais de 20 pessoas), prefira `DataTable`.
